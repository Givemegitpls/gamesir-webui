# Фикстуры

Сняты с живого Cyclone 2 (2.4G донгл, `3537:100b`), дамп от 30 сентября — тот же
снимок, что описан в `dumps/README.md` (сам каталог `dumps/` в git не попадает).

- `page-01`…`page-05`, `page-32` — страницы профилей/подсветки: 680 байт у профиля,
  635 у подсветки.
- Имена профилей в этих файлах пустые, мёртвые зоны близки к заводским, флаг
  `xinput_abxy_change` (0x2c) = 0. Ничего идентифицирующего устройство в файлах нет.

| Файл | Что проверяет |
|---|---|
| `page-02.bin` | профиль в раскладке Xbox (`readLayout().switchLayout === false`) |
| `page-04.bin` | раскладка switch **только** через ремапы A/B/X/Y, без флага 0x2c |
| `page-32.bin` | страница подсветки: геометрия анимаций, инвертированная скорость, round-trip |
| `page1-frames.json` | сырые кадры обмена с падом (чтение профиля 1, версии прошивки) |

Используются в `tools/test-protocol.mjs`; пути относительные, от каталога `tools/`.
Если снимаешь свой дамп (`tools/c2.py dump DIR`), фикстуры можно обновить из него.
